# TrabalhoAlgoritmo
Algoritmo - 1º Semestre. Professor Ed

Tema: Jogo de corrida
Objetivo: Criar algoritmo em portugol referente a um jogo de corrida e criar um codigo em python que rode o jogo.
Estrategia: Cada integrante irá escrever um algoritmo base em portugol e em python. Após isso iremos escolher um como base para ir evoluindo o jogo

A primeiro momento o jogo será simple, contendo uma matriz que definirá o BOARD, preencher com o jogador, e aleatorizar apariçoes de obstaculos. A primeiro momento o game loop será reiniciado após o input do usuario.
